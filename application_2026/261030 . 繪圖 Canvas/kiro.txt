程式在做什麼
一個 worker thread 持續產生資料（sin 波 + 雜訊，模擬感測器 20Hz 取樣），透過 thread::send -async 送回主 thread，由主 thread 用 Canvas 即時畫出平滑曲線，像心電圖一樣向左捲動。有「開始 / 暫停 / 清除」按鈕。

核心架構（教學重點）

Worker Thread (算資料)  ──thread::send -async──>  Main Thread (畫 Canvas)
最關鍵的 3 個觀念（README 有詳細逐段解說）：

Tk 不是 thread-safe — GUI 只能在主 thread 操作。worker 絕不能直接畫 Canvas，只能把資料「送回」主 thread 畫。

用 thread::send -async 傳資料 — 非同步送出不等待，worker 送完立刻繼續算，才能真正平行、UI 不卡。

worker 用 after 排程，不用 while 迴圈 — 事件驅動，且結尾一定要 thread::wait 進入事件迴圈，否則 thread 執行完就死、after/send 都不運作。

要改成你自己的應用
只要把 gen_one 裡的這行換掉：

tcl

set val [expr {sin($t) + (rand()-0.5)*0.3}]   ;# 模擬資料
;# 改成讀序列埠、讀檔、或你的量測函式
其他（送回、畫圖、捲動）完全不用改——這就是分層設計的好處。
